# E-Commerce Backend API

RESTful backend application built using Java, Spring Boot, Spring Data JPA, Hibernate and MySQL.

## Features

- CRUD Operations
- Product Search
- Pagination
- Sorting
- DTO Pattern
- Validation
- Global Exception Handling
- Swagger UI Documentation

## Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Swagger UI
- Postman
- Git & GitHub

## API Endpoints

- GET /products
- GET /products/{id}
- POST /products
- PUT /products/{id}
- DELETE /products/{id}
- GET /products/search?name=
- GET /products/page?page=0&size=5
