# E-Commerce Backend API

A RESTful backend application built using Java, Spring Boot, MySQL, JPA, and Hibernate.

## Features

- CRUD Operations
- Product Search
- Pagination
- Sorting
- Input Validation
- Global Exception Handling
- Swagger UI Documentation

## Tech Stack

- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Swagger UI
- Postman
- Git & GitHub

## API Endpoints

- GET /products
- GET /products/{id}
- POST /products
- PUT /products/{id}
- DELETE /products/{id}
- GET /products/search?name=
- GET /products/page?page=0&size=5
- GET /products/sort?field=name
